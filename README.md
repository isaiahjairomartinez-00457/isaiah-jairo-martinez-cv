# Isaiah Jairo Martinez — Personal CV Website

A responsive personal Curriculum Vitae website for Isaiah Jairo Martinez, an aspiring AI developer and 4th Year BSIT student at Davao del Norte State College.

## Technologies used

- HTML5
- CSS3
- Vanilla JavaScript
- Responsive design and accessible semantic markup
- Local image assets

## Project structure

isaiah-cv/

## Run locally

Open `index.html` directly in a browser, or serve the `isaiah-cv` folder with any simple static web server. No package manager or build step is required.

## Features

- Responsive desktop, tablet, and mobile layouts
- Mobile navigation toggle with Escape-key support
- Active section navigation and reading-progress indicator
- Reduced-motion support and subtle scroll-reveal transitions
- Direct email, phone, GitHub, and project repository links
- Browser print dialog for saving a clean PDF CV

## GitHub Pages deployment

1. Create a GitHub repository and upload the contents of this folder to the default branch.
2. Open **Settings → Pages** in the repository.
3. Select **Deploy from a branch**, choose the default branch, and choose the `/ (root)` folder.
4. Save and wait for GitHub Pages to publish the site.

## Vercel deployment

1. Push this project to a GitHub repository.
2. Sign in to Vercel and select **Add New → Project**.
3. Import the GitHub repository.
4. Keep the framework preset as **Other** or **No Framework**.
5. Leave the build command empty and set the output directory to the folder containing `index.html` (use the repository root if these files are at the root).
6. Select **Deploy**.
